# Модуль приёма данных от устройств по протоколу DataIOApp

Реализация приёма данных от устройств по протоколу DataIOApp.  
*DataIOApp - реализация протокола DataIO для обмена по UDP. Отсутствует заголовок пакета. Пакет UDP используется как контейнер соообщений DataIO.*

Проект содержит:
- Модуль `DataIoReader`, реализующий приём и разбор данных.
- Программу для тестирования модуля. Может использоваться как образец по использованию API. Также содержит модуль записи данных в файл `DataSaver`.

----
## Модуль приёма данных

Модуль `DataIoReader` содержит набор классов, реализующих операции формирования запросов, передачи, приёма и разбора входящих пакетов.

`DeviceTxConnect` - формирование запросов к устройствам и передача по UDP.

`Reader` - контейнер объектов, реализующих передачу запросов к устройствам, приём и разбор сообщений и вызов прикладных обработчиков.

`DataIoAppRx` - разбор входящего пакета и выделение сообщений. Сообщения передаются внешним обработчикам в соответствии с типом сообщения.

`DataIoAppTx` - Формирование сообщений и запись в выходной пакет.

В каталоге doc содержится диаграмма взаимодействия объектов и методов модуля.


### DeviceTxConnect
Передача исходящих запросов в устройство - блок измерения или концентратор связи.

*Устройством* может являться блок измерения (БИ) или концентратор (КС), передающий данные от нескольких БИ.

Выполняет функции:  
- Интерфейс для запросов чтения и записи регистров устройства
- Периодическое формирование запросов на передачу данных
- Передача сообщений о подтверждении приёма данных
- Передача данных по UDP
 
Содержит UDP Client, для которого создается соединение с отдельным устройством с заданными IP адрес + порт.

Передача данных по UDP выполняется в фоновом потоке. В потоке выполняются действия:  
- Периодически формируются запросы данных
- Передаются подтверждения приёма данных на номера принятых пакетов
- Передаются пакеты из очереди внешних запросов. В очередь заносятся пакеты, сформированные при запросах на чтение или запись параметров (регистров) устройства.

#### Передача подтверждения приёма данных
При приёме блока данных метод `Reader.handleMsgAppType()` вызывает метод `DeviceTxConnect.notifyData()`, в который передаётся номер принятого пакета. Номер пакета заносится в очередь `DeviceTxConnect.ackPacketNumbers`. Метод потока `DeviceTxConnect.threadTxRun()` получает из очереди номер пакета, формирует сообщение `MsgApp_DataAcknowledge` и передаёт его в устройство.

### Reader
Содержит массив объектов `DeviceTxConnect`. Каждый объект реализует подключение и передачу для одного устройства.

Содержит UDP клиент, выполняющий приём данных на один порт от всех устройств. Приём данных выполняется в фоновом потоке в методе `Reader.threadRxRun()`. Принятые данные передаются на разбор в `DataIoAppRx.parse()`, который выделяет сообщения из принятого пакета и вызывает `Reader.rxMessageHandler()`. В `rxMessageHandler()` вызываются обработчики для отдельных типов сообщений.

## Интерфейс к приложению

### Конфигурация UDP
При инициализации в `Reader` передаётся массив объектов `UDP_Config`. Каждый объект содержит настройки UDP для одного устройства - IP адрес и UDP порт. Для каждого объекта массива в `Reader` создаётся объект `DataTxConnection` с данной конфигурацией.

### Управление
`Reader` содержит методы `start()` и `stop()`, выполняющие пуск и останов передачи запросов и приёма данных от устройства.

### Callbacks
В `Reader` передаются методы делегатов, которые вызываются модулем при приёме сообщений:
- `receiveDataBlock()` - приём блока данных
- `receiveParameterValue()` - приём значения параметра
